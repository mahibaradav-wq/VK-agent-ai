# План реализации

## Этап 1. Основа

- FastAPI приложение
- SQLite через SQLAlchemy
- Pydantic схемы
- Health check
- Базовая HTML-страница
- Тестовый контур

## Этап 2. Контентный workflow

- Создание товаров, идей, задач и контента
- Версионирование контента
- Mock-ревизия
- Approval владельцем
- Запрет публикации без approval

## Этап 3. Mock-публикация

- VK/Ozon/Telegram mock adapters
- Идемпотентность публикации
- Mock-метрики
- Audit log

## Этап 4. AI-функции

- Генерация идей
- Генерация черновиков
- Ревизия текста
- Подбор товара к материалу
