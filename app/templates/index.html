Mock MVP

Дом по полочкам

Локальная система управления контентом и товарами для VK-сообщества. Публикация во внешние сервисы отключена и заменена mock-ответами.

  • Approval обязателен перед публикацией
  • Изменение материала создаёт новую версию
  • Повторная публикация той же версии идемпотентна
  • Действия фиксируются в audit log
  • Mock AI создаёт идеи и черновики без внешних LLM API
  • Mock Ozon импортирует товары, Telegram пишет уведомления локально
